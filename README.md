# Analyzing the cves

After fetching the raw results for every vendors the output files are hardcoded in `enrich.py`:
```py
JSON_FILES = {
    'Qualcomm': 'saved_json/cve_qualcomm_clean.json',
    'Samsung':  'saved_json/cve_samsung_clean.json',
    'MediaTek': 'saved_json/cve_mediatek_clean.json',
    'Unisoc':   'saved_json/cve_unisoc_clean.json',
}
```

And we now just need to run the script:
```
$ python3 enrich.py
...
```

It will dump the charts in `pic/` and print out the statistics.

# Details

What `enrich.py` is doing (the main logic resides in `load_raw_data`) is basically:
- fetching the raw json files
- fetching the typst cve entries
- checking whether the cwe is memory related or not, it not the entry is discarded
- associating based on the description and based on hardcoded heuristics a set of subsystems the cve is affecting (the protocol)
- attributing an impact based again on the description and on hardcoded frozensets (rce, lpe, dos, dos / rce)
- running the analysis based on the collected results (the charts and the statistics)
